# Code of Conduct

We are committed to a safe and inclusive community.

## Expected behavior
- Be respectful and constructive.
- Assume good intent and give helpful feedback.
- Focus on the work, not the person.

## Unacceptable behavior
- Harassment, hate speech, or personal attacks.
- Publishing private information without consent.
- Spam, scams, or disruptive behavior.

## Enforcement
Project maintainers may edit or remove content and ban users for violations.

## Reporting
Report issues via the repository issue tracker or the security channel in SECURITY.md.
