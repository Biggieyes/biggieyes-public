# Governance

This project is maintained by the core BiggiEyes maintainers.

## Decision process
- Changes are proposed via issues or pull requests.
- Maintainers review for correctness, security, and product impact.
- Decisions use lazy consensus: if no maintainer objects within a reasonable time, the change may proceed.

## Releases
- Releases are tagged in Git and documented in CHANGELOG.md.
- Security fixes may be released out of band.

## Maintainer responsibilities
- Keep dependencies updated.
- Review security reports in a timely manner.
- Ensure that documentation reflects current behavior.

## Community input
- Feature requests are welcome through issues.
- Significant changes should be discussed before implementation.
