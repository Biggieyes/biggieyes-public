# CRE Simulation Evidence

This folder stores artifacts generated by:

```bash
node scripts/cre/simulate-cre-workflow.mjs --dry-run
```

Or by CLI mode:

```bash
node scripts/cre/simulate-cre-workflow.mjs
```

## Files
- `cre-sim-<timestamp>.json`: machine-readable result
- `cre-sim-<timestamp>.md`: human-readable summary
- `latest.json`: latest run snapshot
- `latest.md`: latest run summary

## Notes
- `--dry-run` creates reproducible evidence even when CRE CLI is not installed.
- For final submission evidence, run without `--dry-run` on a machine with CRE CLI configured.
