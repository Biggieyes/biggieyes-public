# FAQ

## Is this open source?
Yes. The client and serverless code are public.

## Which network does it use?
Polygon Amoy testnet by default (chainId 80002). You can configure mainnet by updating addresses and RPC settings.

## Do you store private keys?
No. All signing is done in the user's wallet.

## How is randomness handled?
Randomness is provided by VRF on chain. The UI only displays the result.

## What data is stored for chat?
Wallet address, message content, timestamps, and moderation actions.

## Can I self host?
Yes. See docs/DEPLOYMENT.md.

## Is this financial advice?
No. See docs/RISK_DISCLOSURE.md and legal/TERMS.md.
