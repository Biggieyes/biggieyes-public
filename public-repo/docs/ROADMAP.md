# Roadmap

This roadmap is directional and may change.

## Now
- Publish the public repository and clean documentation.
- Improve onboarding and error messaging.
- Harden rate limiting and monitoring for public endpoints.

## Next
- Add optional indexer for faster historical views.
- Expand test coverage for mint and rewards flows.
- Provide mainnet-ready configuration.

## Later
- Multi-chain support.
- Community governance tooling.
- Advanced analytics and data exports.
