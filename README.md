# a-gamified-on-chain-NFT-lottery-with-dynamic-pricing-and-integrated-DeFi-tokenomics
BiggiEyes — a gamified on-chain NFT lottery on Polygon. Mint tradable tickets and redeem to trigger Chainlink VRF and assign on-chain metadata. Dynamic block pricing, weekly BIGGI token rewards, and DeFi mechanics (reserve, buyback, drip) for sustainable liquidity.
