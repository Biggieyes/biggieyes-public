## Short Project Summary

BIGGIEYES is a Web3 NFT ecosystem on Polygon where users mint tradable tickets, redeem them into provably random NFTs, and participate in a transparent token economy powered by BIGGI, buybacks, treasury routing, liquidity management, and collector rewards.
