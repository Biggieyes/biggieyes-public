# Security Policy

## Supported versions
- The main branch and the latest tagged release.

## Reporting a vulnerability
- Use GitHub Security Advisories for this repository.
- If advisories are not available, email security@biggieyes.com.
- Do not post sensitive details in public issues.

## Response targets
- Acknowledge within 72 hours.
- Triage within 7 days.
- Provide status updates at least every 14 days.

## Scope
- Frontend code in `src`.
- Serverless functions in `functions`.
- Build and deployment config in this repo.

## Out of scope
- Third party services and infrastructure that are not controlled by this repo.
- Smart contracts unless explicitly deployed and referenced in the repo.

## Safe harbor
Good faith security research is appreciated and will not result in legal action.
