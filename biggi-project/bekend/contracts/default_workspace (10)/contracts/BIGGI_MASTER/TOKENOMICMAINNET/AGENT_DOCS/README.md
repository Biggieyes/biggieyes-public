# Agent docs index

This folder holds auxiliary agent-facing notes for the `TOKENOMICMAINNET` branch.

It is a support layer around the real source tree:

- tokenomic contracts live in `..`
- tokenomic libraries live in `../TOKENOMIC_LIBRARY`
- tokenomic readers live in `../TOKENOMIC_READERS`
- core contracts referenced by tokenomics live in `../../CORE`

## What this folder is for

- branch-level audits
- implementation notes
- agent summaries for individual contracts and libraries
- local verification context

## What this folder is not

- not the source of truth for runtime behavior
- not a replacement for Solidity source
- not a replacement for the contract dossiers in `../MAINNET_CONTRACT_DOSSIERS`
