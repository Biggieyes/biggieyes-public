# Mainnet Contract Dossiers

This package contains professional per-contract mainnet dossiers for the most critical BIGGI contracts.
Each dossier includes:
- contract role and integration map
- mainnet-vs-testnet delta summary
- privileged actions map
- audit notes and runtime monitoring checklist
- frozen ABI copy (when available)
