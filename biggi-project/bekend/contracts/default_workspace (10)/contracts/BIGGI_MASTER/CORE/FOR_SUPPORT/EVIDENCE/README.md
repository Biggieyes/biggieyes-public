# Evidence Files

This folder contains copied public JSON reports generated from repository tooling. These files are safe to share with Chainlink/PolygonScan support because they contain public contract addresses, transaction hashes, verification status, and preflight state. They must not be mixed with `.env`, private keys, API keys, or signed legal documents.

Expected files:

- `deployment-manifest-polygon.json`
- `core-series-source-verification-polygon.json`
- `core-series-verification-polygon.json`
- `cre-preflight-polygon.json`
- `launch-readiness-polygon.json`
- `cre-receiver-deployment-plan-polygon.json`
- `initial-distribution-polygon.json`
- `initial-liquidity-polygon.json`
- `tokenomics-activation-polygon.json`
- `core-relationships-polygon.json`
- `collection-rewards-redeploy-polygon.json`
- `collection-rewards-claims-audit-polygon.json`
