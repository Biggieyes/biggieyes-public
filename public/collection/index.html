Collection Structure

BiggiEyes Collection

The BiggiEyes collection is organized around chapters, block-based outcomes, and rarity progression that becomes visible after the ticket reveal flow. This page explains the structure before you enter the live grid inside the app.

Open Collection In App See VRF Mint Flow

Collection signals that matter

Block pricing

Public pricing follows the collection state instead of remaining flat, so the collection view needs to show current block-oriented pricing rather than only an initial mint number.

Mint counts

Mint counts help explain scarcity and progression across blocks and chapters, which is why the app grid is more useful after the topic has been explained on a static page first.

Rarity path

The final NFT outcome depends on the reveal path, so collection structure and VRF logic should be understood together rather than as separate isolated mechanics.

Why this page exists

Search visitors looking for a collection overview usually want a stable explanation page, not an immediate wallet dashboard. The app still exposes the most detailed view, but this URL gives the collection topic a cleaner and more crawlable entry point.

Key points

  • Chapters begin with a VRF-focused ticket phase before public mint opens.
  • Block prices and mint counts are part of the collection state.
  • Collection completion connects directly to the rewards side of the app.
