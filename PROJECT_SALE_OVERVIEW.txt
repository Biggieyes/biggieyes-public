PROJECT: BIGGIEYES / BIGGINFTWEB
VERSION: Sale Overview (2026-01-31)

EXECUTIVE SUMMARY
BiggiEyes is an on-chain NFT ecosystem built around verifiable randomness (VRF), dynamic pricing, and a transparent tokenomics dashboard. It combines a ticket -> VRF -> NFT flow, IPFS-hosted assets, and a full ecosystem UI (stats, rewards, liquidity, treasury, buyback, DRIP) into a production-ready front-end. The system is designed for trust: live prices, mint counts, and reward metrics are read directly from contracts and shown in real time.

MARKETING / INVESTOR NARRATIVE
- Fairness: VRF makes outcomes provably random.
- Transparency: live on-chain stats show the real state of the economy.
- Momentum: dynamic pricing rewards early participation and signals demand.
- Utility: buyback, DRIP, and LM create a full ecosystem loop.
- Expansion: modular architecture supports rapid new features and markets.

PRODUCT OVERVIEW
- VRF-based NFT minting where the final NFT is selected randomly from IPFS.
- Dynamic block pricing that rises with mint activity and background influence.
- A complete, unified interface for minting, redeeming, rewards, liquidity, and tokenomics.

CORE USER FLOW (END-TO-END)
1) Ticket Mint
   - User mints a ticket.
   - Ticket price is on-chain and surfaced live.

2) Ticket Redeem -> VRF
   - Ticket is redeemed to trigger a VRF request.
   - VRF selects the final NFT from IPFS.
   - Full status and history are shown in the VRF panel.

3) NFT Delivery
   - On fulfillment, the NFT is minted and appears in the user gallery.
   - UI auto-refreshes stats, rewards, and mint history.

DYNAMIC PRICING MODEL (LIVE VS BASE)
- Base price: a starting reference (1-10 POL) per block.
- Live price: on-chain price that rises with mint demand.
- Matching background color increases the same block price.
- Users always see both reference and live pricing for transparency.

TOKENOMICS AND ECONOMY (DEEP DIVE)
Token Layer
- Biggi token is integrated across the ecosystem panels.
- Live token price uses on-chain feeds and DEX pricing fallbacks.
- LP price and reserve/treasury balances are visible in Live Stats.

Distribution Layer
- A Multi-Collection Distributor routes value to rewards pools and ecosystem wallets.
- Community and collection allocations are tracked on-chain.
- Claimable rewards are displayed with real-time snapshots.

Buyback Engine
- Buyback Agent contract executes market buybacks.
- Policy-controlled slippage and deadlines protect execution quality.
- Totals and wallet flows are visible in the tokenomics dashboard.

DRIP System
- DRIP Distributor and DRIP Keeper enable continuous reward flow.
- DRIP LM provides liquidity incentives tied to the ecosystem.
- DRIP caps, availability, and claims are read directly from contracts.

Liquidity Management (LM)
- Liquidity Manager and Liquidity Automation contracts are integrated.
- Router/Factory/Pair references allow live DEX pricing and LP health checks.
- Liquidity previews give real-time transparency of pool status.

Reserve & Treasury
- Reserve and Treasury modules track total received, balances, and allocations.
- Snapshots include reserve balances, waiting amounts, and refill metrics.
- These values are surfaced in the ecosystem dashboard for full transparency.
